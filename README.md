# Hangman Game

A fun and interactive Hangman game built with HTML, CSS, and JavaScript!

## 🎮 Play the Game

**[Play Hangman Here](https://github.com/seanmarlon903/hangman)**

Simply click the link above to start playing! Guess the word letter by letter before running out of attempts.

## 📋 How to Play

1. A random word is selected
2. Guess one letter at a time
3. You have a limited number of incorrect guesses
4. Try to guess the word before the hangman is complete!

## 📁 Project Structure

- `hangman.html` - Main game interface
- `script.js` - Game logic and functionality
- `style.css` - Game styling and layout

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

Enjoy the game! 🎯
